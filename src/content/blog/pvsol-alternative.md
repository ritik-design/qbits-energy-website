## Why Designers Look for a PV*SOL Alternative

### Desktop install, Windows-only
PV*SOL is a desktop application, and Valentin lists Windows 10 and 11 as the system requirements, with no macOS, Linux or browser build listed as of writing. Mac and Linux users generally run a virtual machine, dual-boot, or skip it. SurgePV is browser-based on any modern device.

### Regional scope
PV*SOL is strongest in Germany and central Europe, which is what it was built for. Tariff and code coverage outside that region is not where the product is positioned. SurgePV ships NEC, IEC, AS/NZS, IS code libraries with [PM Surya Ghar](/glossary/pm-surya-ghar/), SREC, [FiT](/glossary/feed-in-tariff/), and Einspeisevergütung tariffs out of the box.

### Proposal and financial stack sit elsewhere
PV*SOL's deliverable is a branded technical project report rather than a financed, e-signable sales proposal, and it is not positioned as a sales system. Confirm current scope with Valentin Software. SurgePV ships [solar financial modeling](https://surgepv.com/generation-financial-tool), [branded solar proposals](https://surgepv.com/solar-proposals), and bankable yield in the same project.
