Industry-standard bankable simulator since the late 1990s. Windows-only desktop. ~€500 per user per year. Lender-mandated on some first-of-its-kind projects.

Strong 8,760-hour browser simulator. No native proposal builder. $99 to $300+ per user per month.

German desktop tool. Windows-only. Regional focus, weaker outside Europe. ~€1,000 per user per year.

### 5. SAM / PVWatts (free, research)
NREL's open-source simulators. Excellent for research and sensitivity studies. Not production-grade for EPC workflows.
