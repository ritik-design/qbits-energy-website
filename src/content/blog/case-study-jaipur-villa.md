> **Illustrative planning scenario, not a customer case study.** The 10 kW capacity is a working brief, not a recommendation. Qbits has not supplied a signed customer record, site survey, interval load file, design, quotation, commissioning report or measured performance dataset for this page. Every project outcome is therefore not established.

A large home can have high summer demand, but floor area and appliance count do not determine solar capacity. This scenario shows how to test a 10 kW idea using bills, interval load, roof geometry and current connection rules.

## What decision does this scenario test?

The question is not whether 10 kW “works” in the abstract. The question is whether that AC capacity, paired with a documented PV array and connection design, fits the site's measured daytime load, available area, electrical infrastructure and approval route.

A credible answer must be electrically safe, acceptable under the current project process, and commercially supportable after every cost and uncertainty is shown.

A missing input should stay not established. Replacing it with a typical value creates a neat result but not a reliable decision.

## Engineering controls for this site

- Do not promise that solar will run a stated number of air conditioners without a load and architecture review.
- Separate daytime bill offset from outage backup.
- Use module temperature and inverter derating data rather than a generic desert rule.

A residential design should show which loads remain grid-only, which are on a backup board, and how the system behaves during an outage. Subsidy and metering claims must match the current applicant and DISCOM process.

The responsible electrical professional should sign the single-line diagram, protection settings and commissioning plan. Any safety-critical or production-critical system needs an independent continuity plan. Grid-connected solar is not backup unless the complete design explicitly supports that role.

## How should the commercial case be calculated?

Use measured inputs and keep the calculation reproducible:

1. **Estimated annual generation** = simulation output for the documented array, orientation, losses and weather dataset.
2. **Self-consumed energy** = the lesser of generation and coincident site load in each interval.
3. **Exported energy** = generation minus self-consumed energy, subject to the approved metering arrangement.
4. **Annual bill effect** = avoided import charges plus documented export credit minus fixed, demand, finance, service and maintenance costs.
5. **Simple payback** = eligible project cost divided by annual net cash benefit.

Do not publish a generation, saving, return or payback result until the calculation file identifies every input, unit, date and source. Tax effects require written advice from a qualified professional. Financing results require actual lender terms.
