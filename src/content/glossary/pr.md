## What is Performance Ratio

Performance Ratio (PR) is the ratio of actual energy generated by a solar PV plant to the energy that would have been generated at the same plane-of-array irradiance under ideal [Standard Test Conditions (STC)](/glossary/stc/). PR is a dimensionless number expressed as a percentage and is the standard quality metric for solar plant performance.

PR isolates plant quality from weather and location. Two plants in different cities can be compared on PR even though their [CUF](/glossary/cuf/) differs because their irradiance differs. PR captures the cumulative effect of all loss mechanisms: shading, [soiling](/glossary/soiling/), [temperature coefficient](/glossary/temperature-coefficient/) losses, cable losses, module mismatch, [inverter efficiency](/glossary/inverter-efficiency/) shortfalls, equipment failures and [degradation](/glossary/degradation/).

For Indian utility solar plants, well-designed and well-maintained PR lands at 78 to 82 percent. C&I rooftop typically 75 to 80. Residential rooftop 72 to 78. New commissioning PR is the highest a plant will achieve; it declines slowly through the operating life due to degradation and ageing.

> **TL;DR**
> - Performance Ratio (PR) is actual energy output divided by the energy expected at the same irradiance under STC, isolating plant quality from weather and location.
> - Indian PR benchmarks: 78 to 82 percent for new utility plants, 75 to 80 percent for C&I rooftop, 72 to 78 percent for residential rooftop.
> - PR strips out roughly 18 to 30 percent of total loss from soiling, temperature, cable losses, mismatch and inverter inefficiency.
> - PR is temperature-sensitive: a plant at 60°C cell temperature runs 8 to 12 percent lower instantaneous PR than at 25°C.
> - PR differs from CUF: PR is a quality metric normalised for irradiance, while CUF is the bottom-line annual output ratio against nameplate.
> - Commissioning PR is the highest a plant will ever hit, typically declining from 78 to 85 percent at Day 1 to 65 to 72 percent by Year 25.

## PR explained simply

Two solar plants, one in sunny Jodhpur and one in cloudy Kolkata. The Jodhpur plant makes more energy because it gets more sunshine, not because it is better. PR strips out the sunshine difference. Both plants get scored on what they did with the sunlight they received.

A 100 kW plant getting irradiance equivalent to 1,000 kWh per kW should produce 1,000 kWh (ideal). If it produces 800 kWh, the PR is 80 percent. That 20 percent gap is all losses: heat, soiling, wires, inverter, etc.

## Why PR matters

Plant quality benchmark. Comparable across geographies.

Commissioning acceptance. PR threshold is the pass criterion for handover.

O&M target. Annual PR target is the operational KPI for plant operators.

Degradation tracking. Year-on-year PR decline shows ageing rate.

PPA terms. Some contracts reference PR alongside CUF.

Diagnostic tool. PR shortfalls point to specific loss mechanisms.

## How PR is calculated

PR = E_actual / (P_nameplate × H_POA / G_STC)

Where:
- E_actual = actual energy generated (kWh)
- P_nameplate = plant rated capacity (kW)
- H_POA = plane-of-array irradiation over the period (kWh/m²)
- G_STC = STC irradiance = 1 kW/m²

Example: 1 MW plant generates 4,800 kWh in a day, with H_POA = 6 kWh/m².
PR = 4,800 / (1,000 × 6 / 1) = 4,800 / 6,000 = 0.80 = 80 percent.

## Technical deep dive

### Loss budget for typical Indian plant

| Loss component | Typical magnitude |
|---|---|
| Module nameplate vs delivered | 0 to 3% |
| Module mismatch | 1 to 3% |
| Soiling | 3 to 8% (annual average) |
| Shading | 1 to 5% |
| Cell temperature | 5 to 10% |
| DC cable loss | 1 to 2% |
| Inverter efficiency loss | 1 to 3% |
| AC cable and transformer loss | 1 to 2% |
| Availability | 1 to 3% |
| Total loss | 18 to 30% |
| Resulting PR | 70 to 82% |

### PR variants

| Variant | Definition |
|---|---|
| Standard PR | E_actual / (P × H / G_STC) |
| Temperature-corrected PR | PR with temperature derate normalised out |
| Annual PR | Yearly average |
| Hourly PR | Time-resolved, for diagnostics |

### Temperature impact

PR is temperature-sensitive because module efficiency drops at high cell temperature. A plant operating at 60°C cell temperature has 8 to 12 percent lower instantaneous PR than at 25°C, the same effect that explains [why solar inverters produce less in Indian summer](/blog/solar-inverter-summer-derating-india/).

### Commissioning vs operational PR

| Stage | Typical PR |
|---|---|
| Day 1 acceptance test | 78 to 85% |
| Year 1 | 76 to 82% |
| Year 10 | 73 to 78% |
| Year 25 | 65 to 72% |

## Advantages

Captures plant quality independent of weather.

Standardised globally.

Diagnostic value for loss identification.

Suitable for cross-location comparison.

## Limitations

Requires accurate plane-of-array irradiance measurement.

Sensitivity to sensor calibration.

Less intuitive than CUF for non-technical audiences.

Aggregating to annual PR hides intra-day patterns.

## Common problems

Pyranometer drift causing inaccurate PR measurement.

Misplaced sensors not representative of array average.

Shading not captured in irradiance reference, which is why utility-scale bids increasingly run formal [shading analysis](https://surgepv.com/shadow-analysis/) before finalising layout.

Soiling on irradiance sensor itself.

[Inverter clipping](/blog/inverter-clipping-explained/) understating apparent PR.

PR target set without accounting for site-specific degradation.

## Best practices

Install calibrated pyranometers in array plane.

Clean sensors regularly.

Track PR continuously through SCADA.

Compare daily PR to expected to catch anomalies early.

Audit annual PR for ageing rate against warranty, ideally alongside a [pre-monsoon inspection](/blog/pre-monsoon-solar-inspection-checklist/) so anomalies are caught before the rainy season.

Use temperature-corrected PR for quality assessment.

## Comparison: PR by plant type

| Plant type | Typical PR |
|---|---|
| Utility tracker bifacial new | 80 to 84% |
| Utility fixed-tilt new | 78 to 82% |
| C&I rooftop | 75 to 80% |
| Residential rooftop | 72 to 78% |

EPCs delivering C&I rooftop installations or residential rooftop systems should set PR targets appropriate to each segment before commissioning, since acceptance thresholds differ meaningfully by plant type.

## Indian market context

SECI utility tender bids include PR as a quality metric, with commissioning acceptance threshold typically 78 to 80 percent.

State CGS (Captive Generation Schemes) reference PR in PPA terms.

Major IPPs publish annual PR figures in sustainability reports.

CEA encourages PR reporting in plant performance dashboards.

O&M contracts increasingly include PR-based incentive and penalty clauses.

## Common mistakes

Using poorly placed or uncalibrated irradiance sensors.

Comparing PR across plants without normalising for technology.

Ignoring inverter clipping when interpreting PR.

Setting PR targets without accounting for site climate.

Allowing soiling to accumulate, reducing PR slowly.

Not auditing PR trends for degradation.

## Key takeaways

Performance Ratio is the quality grade of a solar plant. It strips weather and location out of the comparison, focusing on what fraction of available irradiance was converted to electricity. Indian utility plants target 78 to 82 percent PR at commissioning. Soiling, temperature, shading and equipment quality determine the actual figure. PR diagnostics identify specific loss mechanisms when actual falls short of expected.
