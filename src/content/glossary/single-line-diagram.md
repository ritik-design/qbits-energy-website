**A solar single line diagram, or SLD, shows how the principal electrical components connect from the PV array to the inverter, protection devices, loads, meter and grid.** It simplifies a multi-conductor system into an overview. It does not replace detailed cable schedules, installation drawings or a site-specific safety design.

## What should the drawing show?

| Part of the system | Details worth checking |
| --- | --- |
| PV array and strings | Module count, string grouping and relevant DC ratings |
| Inverter | Exact model, DC inputs, AC output and rated limits |
| DC and AC protection | Isolation and protective devices, locations and ratings |
| Earthing and bonding | Intended connections and design references |
| Meter and grid point | Approved metering arrangement and connection location |

The required level of detail depends on project size and the reviewer. A domestic rooftop submission and a large commercial plant will not use the same drawing set. Ask the serving [DISCOM](/glossary/discom/) for its current SLD format and approval checklist; ask the project engineer whether any electrical-inspector or [CEIG](/glossary/ceig/) review applies. Do not assume that a single national capacity threshold determines whether CEIG review or an engineer seal is needed.

## How to review an SLD before installation

Confirm that the drawing's inverter and module models match the quotation. The PV string count and input range should agree with the inverter datasheet and the [string-sizing calculation](/string-sizing-calculator/). Check that protective devices are identified, not just represented by unlabeled boxes. Record the drawing revision and any design changes. After installation, obtain an as-built version if the constructed connections differ from the approved design.

An SLD explains **electrical relationships**. A roof layout explains physical module placement; a wiring diagram gives more conductor-level detail. The [solar inverter wiring guide](/blog/solar-inverter-wiring-diagram/) provides a visual explanation but should not be used as a substitute for an engineer-approved site drawing.

## Who prepares it?

A competent solar electrical designer or engineer should prepare and check a project SLD. A software-generated drawing still needs human review of ratings, protection and the actual installation. Local sign-off requirements depend on the state, connection size and authority; verify them for your project rather than relying on a national rule-of-thumb.

Check the exact submission and approval rules with the local DISCOM and state authority for each project.
