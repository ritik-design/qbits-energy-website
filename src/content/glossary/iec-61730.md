## What is IEC 61730

IEC 61730 is the international safety standard for photovoltaic modules used in terrestrial applications. The standard has two parts: Part 1 specifies construction requirements (materials, design, marking) and Part 2 specifies testing requirements to verify those construction requirements.

The standard works alongside IEC 61215 (qualification and performance) to provide complete module certification. While IEC 61215 verifies durability under stress, IEC 61730 verifies that the module is electrically, thermally and mechanically safe.

For Indian solar, IS 14286 is the harmonised standard that references both IEC 61215 and IEC 61730 requirements. BIS certification under IS 14286 covers both qualification and safety in one certificate, which is why a [solar quotation checklist](/blog/solar-quotation-checklist/) for panels should ask for the BIS licence number alongside the IEC 61215/61730 test reports rather than accepting brochure claims alone.

## Why IEC 61730 matters

Module safety. Ensures modules do not cause electric shock, fire or injury.

Insurance. Insurers require IEC 61730 certified modules.

Building integration. BIPV requires fire safety classification from IEC 61730.

Lifetime safety. Tests cover materials' long-term safety behaviour.

Regulatory compliance. CEA Measures Relating to Safety reference module safety.

## IEC 61730 Application Classes

| Class | Use | Maximum system voltage |
|---|---|---|
| Class A | Unrestricted access, residential | 1500 V |
| Class B | Restricted access, industrial | 1500 V |

Most modern PV modules certified Class A for use in residential and unrestricted environments.

## Test categories

| Category | Tests |
|---|---|
| Preconditioning | UV, thermal, humidity stress |
| Insulation testing | Voltage withstand, dielectric integrity |
| Leakage current | Wet leakage at high voltage |
| Mechanical | Static load, impact |
| Fire | Spread of flame, fire performance |
| Bypass diode | Thermal endurance |
| Hot spot | Partial shade endurance |
| Marking | Required identification |

## Technical deep dive

### Common tests under IEC 61730-2

| Test | Stress condition |
|---|---|
| Robustness of terminations | Bend, twist, pull on cable exits |
| Continuity of bonding | Earth path integrity |
| Voltage withstand | High voltage AC application |
| Insulation resistance | Above 1 MΩ at system voltage |
| Wet leakage | Module wetted, voltage applied |
| Bypass diode thermal | Cell shaded, diode carries current |
| Hot spot endurance | Sustained partial shade |
| Mechanical static load | 2400 to 5400 Pa snow/wind load |
| Hail impact | 25 to 75 mm hailstone |
| Fire spread | ASTM E108 or equivalent |

### Fire classification

| Class | Spread of flame |
|---|---|
| Class A | Withstands severe fire exposure |
| Class B | Withstands moderate fire exposure |
| Class C | Withstands light fire exposure |

Most Indian modules certified Class C or higher under IEC 61730.

### Junction box compliance

PV module junction box safety is covered indirectly through IEC 61730 tests on the complete module. The junction box itself is certified separately under IEC 62790.

## Compliance pathway

1. Manufacturer engages accredited test lab.
2. Sample modules submitted.
3. Construction review per Part 1.
4. Test sequence per Part 2.
5. Compliance report issued.
6. Certificate granted.
7. Re-certification on design changes.

## Common compliance problems

Wet leakage failure with damaged encapsulation.

Bypass diode thermal failure.

Junction box mounting failure.

Fire spread classification below Class C.

Marking deficiencies.

## Key takeaways

IEC 61730 is the safety qualification standard for PV modules, complementing IEC 61215 (qualification and performance). Indian compliance is through IS 14286 / BIS certification covering both standards. The standard verifies electrical, fire, mechanical and material safety. Class A modules are the default for unrestricted access including residential applications. Testing takes 2 to 4 months and is typically run in parallel with IEC 61215.
